# Cambios de ARIELA AGENTE VIRTUAL v0.3.0

- Se sustituyeron avisos de estado contradictorios por mensajes que distinguen demostración local y variables de conexión configuradas.
- Se aclaró que `/api/health` verifica la configuración, no la respuesta real del proveedor.
- Se reforzó el prompt para reducir nombres, presupuestos, estadísticas y porcentajes inventados; pide marcar supuestos y revisar cálculos.
- Se añadieron diálogo de código privado, manejo de errores, límites de solicitud, validación de mensajes y pruebas automáticas.
- Se añadieron decisiones técnicas, matriz de pruebas, registro de estado y pasos de subida desde Android.
- Se mantuvo Node.js provisionalmente para evitar una migración no probada del prototipo existente; la decisión queda documentada para revisión conforme al manual.
