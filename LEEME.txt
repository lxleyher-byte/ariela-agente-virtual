ARIELA AGENTE VIRTUAL · PROTOTIPO 0.3.0

EMPEZAR
1. Descomprime el paquete.
2. Revisa README.md y ESTADO_Y_PRUEBAS.md.
3. Para ejecutar en una computadora con Node.js 20+: npm start
4. Abre http://localhost:3000.
5. Para las comprobaciones automáticas: npm run check y npm test.

IA REAL
La IA real necesita configurar GROQ_API_KEY y ARIELA_ACCESS_CODE en la configuración privada del servidor de alojamiento. Nunca guardes valores reales en GitHub ni en index.html. En modo demo, las respuestas son ejemplos preparados.

IMPORTANTE
Esta versión no tiene cuentas individuales ni memoria permanente, ni voz, avatar animado, pagos o publicación automatizada. Es un prototipo, no un producto final de acceso público.
